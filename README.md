## How to Compile and Run

You need a C compiler, such as GCC, to compile and execute these programs.

1. Clone or download this repository.
2. Open a terminal in the folder containing the C file. 

3. Compile the program:

gcc program1.c -o Myexe

4. Run the program on Windows:

program1.exe

On Linux or macOS, run it using:

./program1
